# Free Online CSV Viewer & Editor

> A fast, secure, lightweight, and 100% in-browser utility tool to view, search, sort, and edit CSV, TSV, and delimited text files.

👉 **Live Demo:** [https://online-csv-viewer-free.github.io/](https://online-csv-viewer-free.github.io/)

---

## 🚀 Overview

**[Free Online CSV Viewer](https://online-csv-viewer-free.github.io/)** is built for developers, analysts, and everyday users who need an instant preview and editor for CSV data without installing bulky software like MS Excel or uploading sensitive files to remote servers.

Everything runs entirely on the **client-side (browser)**, ensuring complete privacy and blazing-fast performance.

---

## ✨ Features

- **100% Privacy Focused:** Files are processed locally inside your browser; no data is ever uploaded or stored on external servers.
- **Instant Search & Filter:** Filter thousands of rows instantly with real-time text matching.
- **Multi-Column Sorting:** Sort any table column in ascending or descending order with a single click.
- **In-Browser Editing:** Double-click cells to update values directly.
- **Export Capabilities:** Export modified data back into clean CSV format.
- **Drag & Drop Support:** Drop any `.csv`, `.tsv`, or `.txt` file straight onto the interface.
- **Zero Dependencies & Fast Loading:** Optimized minimal footprint serving via GitHub Pages.
